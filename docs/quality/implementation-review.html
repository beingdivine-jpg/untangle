IMPLEMENTATION REVIEW · 4 OCTOBER 2026

A clearer first step. Work that stays with you.

The audit’s reproducible data-loss and empty-path defects have been addressed. The product keeps its logo and visual identity, with a simpler beginner journey and clearer boundaries around saving, guidance and AI.

What this release does not claim

Production uses guided local planning and a scripted demo. No live-model evaluation, native-Polish review, practitioner certification, participant research or physical-phone performance study is claimed. These require the people or configuration listed in the remaining validation gates.

One useful instruction at a time

Choose a concern and the apps you use. Read a relevant first step. Keep uncertainty as a question. Return to the plan, or ask for support.

The plan stays in memory through normal app navigation. An encrypted file is optional and is never described as a cloud account or an automatic backup.

What changed for every finding

F01P1Returning to the introduction silently destroys the full plan

One memory-only application session keeps plans, outcomes, history, draft notes and file-copy status across introduction, Home, help and language navigation. Continue my plan is available on the introduction. Refresh, leave and explicit clear remain the privacy boundary.

Implemented
F02P1Keeping another draft replaces previously kept checks without explaining it

Kept companion drafts merge with existing checks, preserving observations and notes. App-scope replacement previews removals and supports undo.

Implemented
F03P1A valid onboarding choice can return an unexplained empty result

Every concern/app combination has a next step. Missing coverage keeps the concern, explains the limitation and opens support instead of an empty plan.

Implemented
F04P2Uncommitted notes and outcome selections disappear during ordinary navigation

Unrecorded outcomes and notes live in the session and encrypted file. The interface distinguishes a draft from a recorded update and offers discard.

Implemented
F05P2An allowed large Unicode plan can be exported but cannot be reopened

Export and import share a 2 MB envelope bound. Maximum validated histories, Unicode and JSON-escaped notes round-trip. Oversize files fail explicitly.

Implemented
F06P2The main AI promise leads to a disabled primary action on production

The working guided planner is primary. Unavailable AI actions are omitted; the demo is labelled scripted. Live AI remains disabled, with an explicit production release gate.

Implemented for current mode
F07P2Account and saving state are accurate in help, but insufficiently visible in the journey

A visible tab/file-copy state explains temporary work, download started, checked copy and later edits. Setup explains no Untangle account. Walkthrough saving and provider sign-in are explicitly separate.

Implemented; user comprehension review pending
F08P2The product asks a novice to learn several workspaces before receiving help

A single introduction leads to concern + apps + the first instruction. Setup hides the full workspace navigation. The companion and old detailed walkthrough are optional paths.

Implemented; participant validation pending
F09P2The companion assumes apps the person has never selected

Both setup and the optional companion expose app choice, including another app and uncertainty. Requests and replies are validated against that service scope.

Implemented
F10P2The picture labelled Your selected checks does not match the kept selection

The diagram uses selected draft checks or the kept plan, includes required preparation, explains its limits and shows the additional-item count. Completion-looking check marks were removed.

Implemented
F11P2A general companion note is attached to an arbitrary first check

The companion note is a plan-level note, separate from check observations. It survives navigation and file export without being attached to the first check.

Implemented
F12P2People can add checks but cannot easily correct the plan's scope

Checks can be removed with dependency disclosure. Apps and concerns can be edited with a removal preview. Undo remains available across internal navigation and restores mode after imports.

Implemented
F13P2Most guides stop short of helping someone who cannot find the setting

Every guide has one instruction at a time and contextual help for missing settings, sign-in and restricted options. Computer-only instructions explain the device boundary. Young/family-account users are directed to help rather than bypassing controls.
