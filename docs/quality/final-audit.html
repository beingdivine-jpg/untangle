How it was checked

The first five regression cases were reproduced failing before their fixes. The final suite exercises real clicks and file operations against the production build. AI response tests use controlled fixtures; they do not claim to evaluate a live model.

  • All existing unit tests for plan dependencies, input validation, encryption, translations, and AI output boundaries.
  • Browser journeys in Chromium, Firefox and WebKit: setup, draft preservation, guide steps, personal/example separation, all six judge-tour stages, editing, approval, result and restart.
  • English and Polish layouts across phone, tablet and desktop widths; keyboard focus, reduced motion and automated WCAG A/AA checks on the tested states.
  • Encrypted download and reopen, wrong passwords, malformed/oversized input, held decryption, cancelled requests, page lifecycle clearing and a deliberately failed plan asset.
  • Manual desktop and phone-size inspection of setup and the Polish walkthrough. Native Safari inspection was attempted, but the Mac was locked; automated WebKit coverage is reported separately.
  • Dependency audit, translation coverage, guide-register consistency, official-source link reachability, GitHub CI and production deployment checks after publication.

What this does — and does not — establish

This is a verified technical release audit, not a certification that all possible defects are absent or that the guidance is safe for every situation. “Reviewed” remains a user report, never an account scan or safety score. The demo is explicitly fictional, and live model access remains disabled in production.

No additional confirmed technical finding remains open within this audit scope. Independent Polish review, low-digital-confidence participant sessions, qualified technology-safety review, physical iOS/Android and screen-reader testing, and live-model evaluation still require people or environments not available in this audit. These are tracked in the existing release gates. No adoption or outcome metric has been invented.
